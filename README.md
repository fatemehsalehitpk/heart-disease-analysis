# Heart Disease Data Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of a Heart Disease dataset using Python.

## Dataset
The dataset contains information about patients and their medical features.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Steps
- Data Inspection
- Data Cleaning
- Handling Duplicate Records
- Outlier Detection
- Exploratory Data Analysis
- Data Visualization

## Objective
The objective is to explore the dataset, understand its features, and identify statistical patterns related to heart disease.

## Files
- `heart_disease_analysis.py`: Python analysis code.
- `heart.csv`: Dataset.

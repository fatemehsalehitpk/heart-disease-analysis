# Heart Disease Data Analysis

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a Heart Disease dataset using Python.

The main goal is to explore the dataset, understand its features, clean the data, and identify statistical patterns through data analysis and visualization.

## Dataset

- Initial records: 1,025
- Number of features: 14
- Missing values: None
- Duplicate records were identified and removed during data cleaning.
- Records after removing duplicates: 302

## Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

### 1. Data Inspection
- Exploring dataset structure
- Checking data types
- Reviewing statistical summaries

### 2. Data Cleaning
- Checking missing values
- Identifying duplicate records
- Removing duplicate records
- Preparing data for analysis

### 3. Exploratory Data Analysis (EDA)
- Analyzing numerical and categorical features
- Studying feature distributions
- Exploring relationships between variables

### 4. Data Visualization
- Histograms
- Boxplots
- Countplots
- Statistical visualizations

## Project Files

- `heart-disease-analysis.ipynb`: Jupyter Notebook containing the analysis and visualizations.
- `heart.csv`: Original dataset.

## Key Learning Outcomes

- Data cleaning and preprocessing
- Exploratory data analysis
- Statistical analysis
- Data visualization
- Working with Python data analysis libraries
